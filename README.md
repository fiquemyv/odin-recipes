
# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. It showcases basic HTML by linking together a few recipe pages.

View the live project at: <https://fiquemyv.github.io/odin-recipes/>

## Features

- A home page with links to individual recipes
- Dedicated pages for each recipe
- Recipe images and ingredient/step lists

## HTML Concepts Practiced

- **Boilerplate** – `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`
- **Headings** – `<h1>` through `<h3>` for page and section titles
- **Paragraphs** – `<p>` for descriptions
- **Links** – `<a>` for navigating between the home page and recipes
- **Images** – `<img>` with `src` and `alt` attributes
- **Lists** – unordered lists `<ul>` for ingredients and ordered lists `<ol>` for steps

## Usage

Open `index.html` in a browser and click any recipe link to get started.
